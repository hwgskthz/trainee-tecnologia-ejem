# Pedra, Papel ou Tesoura

Jogo de Pedra, Papel ou Tesoura desenvolvido em Python durante o Trainee de Tecnologia da EJEM.

## Funcionamento

O usuário informa uma das três opções disponíveis:

- Pedra
- Papel
- Tesoura

O computador realiza uma escolha aleatória, e o programa compara as jogadas para determinar o vencedor.

## Conceitos utilizados

- Variáveis;
- Listas;
- Estruturas condicionais;
- Laço de repetição;
- Funções;
- Validação de entrada;
- Biblioteca `random`;
- Método `random.choice()`;
- Método `.lower()`.
